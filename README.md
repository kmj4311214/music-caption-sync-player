# Music Caption Sync Player

음원을 올리고 자막형 텍스트를 줄 단위로 싱크해 큰 화면으로 확인하는 블랙 골드 스타일의 웹 앱입니다. 프로젝트 데이터와 오디오 파일은 Supabase에 저장하고, Vercel 배포를 기준으로 운영합니다.

## 기능 분석

요청에 포함된 원본 HTML은 임시 폴더 파일이라 현재 작업 공간에서 직접 열 수 없었습니다. 사용자가 설명한 프로그램의 핵심 조건은 다음과 같이 정리했습니다.

- 음원 파일을 넣고 브라우저에서 재생한다.
- 가사나 학습용 텍스트를 줄 단위 자막처럼 보여준다.
- 재생 시간에 맞춰 각 줄의 시작/끝 시간을 찍는다.
- 현재 줄을 큰 화면에 강조하고 앞뒤 문장을 함께 확인한다.
- 텍스트를 보며 이해할 수 있도록 현재 줄 메모와 키워드 보기를 제공한다.
- 프로젝트와 오디오 저장 경로를 Supabase에 저장한다.

## 주요 기능

- 오디오 업로드 및 재생 컨트롤
- 줄 단위 자막 입력, 자동 줄 파싱, 균등 분배
- 현재 재생 시간 기준 싱크 찍기와 시작/끝 시간 직접 수정
- 싱크 편집: 1번 자막부터 표시하며 `싱크 찍기`를 누를 때만 번호 순서대로 다음 자막으로 전환하고 시작/끝 시간을 밀리초 단위로 기록
- 싱크 재생: 저장한 시작 시간에 따라 자막을 자동 전환하며 재생 위치 이동과 다시 재생도 지원
- 이전 취소: 최근 싱크 변경을 한 단계씩 복원하고 이전 자막의 시작 지점에서 일시정지
- 전체 리셋: 음원, 가사, 제목, 메모를 유지하고 모든 싱크 시간을 0으로 초기화
- 극장 화면 모드
- 중앙 자막과 앞뒤 문장을 가로 한 줄로 가운데 정렬하고, 문장 길이와 화면 너비에 맞춰 글자 크기를 자동 조절
- 현재 줄 이해 노트와 키워드 칩
- Supabase 프로젝트 저장/불러오기/삭제
- Supabase Storage 오디오 저장
- JSON 내보내기

## 음악을 들으며 싱크 찍기

1. `싱크 편집` 모드에서 `오디오`로 음원을 선택하고 `가사 / 자막`에 문장을 줄 단위로 입력합니다. 아직 찍지 않은 자막의 시간은 0으로 표시됩니다.
2. 처음에는 1번 자막이 중앙 화면에 표시됩니다. 음원을 재생해도 버튼을 누르기 전까지 1번을 유지합니다.
3. 2번 문장이 시작되는 순간 `싱크 찍기`를 누르면 1번의 끝과 2번의 시작 시간이 함께 기록되고 2번으로 넘어갑니다. 이후 누를 때마다 3번, 4번 순서로 전환됩니다. `다음 자막`에서 다음에 표시할 문장을 확인할 수 있습니다.
4. 마지막 문장이 끝날 때 `싱크 종료`를 누릅니다. 음원이 끝나면 기록도 자동으로 종료됩니다.
5. `저장`을 누르면 음원과 기록한 자막 시간이 Supabase에 저장됩니다. 기록 중인 구간은 저장을 누른 시점까지 저장하며 싱크 찍기는 계속할 수 있습니다. 저장 도중 추가한 내용은 미저장 상태로 남으므로 다시 저장합니다.
6. `싱크 재생` 모드에서 처음으로 돌아가 재생하면 기록한 시간에 맞춰 자막이 전환됩니다. 프로젝트를 불러오면 기본으로 이 모드가 선택됩니다. 다시 찍으려면 `싱크 편집`을 선택합니다.

싱크 편집에서는 재생 시간, 재생 위치 변경, 일시정지, 음원 종료, 싱크 종료만으로 중앙 자막이 다음 번호로 넘어가지 않습니다. 싱크 재생에서는 저장한 시간이 있는 자막만 사용하며 아직 기록하지 않은 줄은 건너뜁니다. 두 모드 모두 확대 화면에서 사용할 수 있습니다.

## 싱크 수정과 리셋

- `이전 취소`는 최근 변경부터 한 단계씩 되돌립니다. 싱크 찍기를 취소하면 이전 자막 번호와 시간을 복원하고 그 자막의 시작 지점에서 음원을 일시정지합니다. 다시 재생한 뒤 올바른 순간에 찍을 수 있습니다.
- 싱크 종료, 줄별 시작/끝 시간 수정, 균등 분배, 전체 시간 이동도 취소할 수 있습니다. 가사와 메모는 취소할 때 지우지 않습니다.
- `전체 리셋`은 모든 줄의 시작/끝 시간을 0으로 지우고 음원을 일시정지한 뒤 처음과 1번 자막으로 돌아갑니다. 선택한 음원, 제목, 가사, 메모는 유지됩니다. 리셋 자체도 `이전 취소`로 복원할 수 있습니다.
- `처음 자막으로`는 기존 싱크 시간을 유지하면서 처음으로 돌아가는 기능입니다.
- 취소 이력은 현재 작업의 최근 100개 변경을 유지합니다. 가사 수정, 음원 변경, 프로젝트 불러오기, 새 프로젝트 생성 시에는 이력을 새로 시작합니다.
- 취소하거나 리셋한 결과는 `저장`을 눌러 Supabase에 반영합니다. 취소 이력 자체는 브라우저의 현재 작업에서만 사용합니다.

## 데이터 저장

Supabase 프로젝트 `taekwondo-promotion-result` 안에 앱 전용 리소스를 추가합니다.

- 테이블: `public.music_caption_projects`
- 버킷: `music-caption-audio`
- 접근 방식: 브라우저별 소유 키를 요청 헤더에 담고 RLS 정책에서 같은 소유 키의 데이터만 허용

스키마 원본은 `database/schema.sql`에 기록되어 있습니다.

### 저장 및 불러오기 안정성

- 저장 전에 연결된 음원의 존재를 확인합니다. 삭제되었더라도 현재 작업의 원본 음원이 남아 있으면 새 경로로 다시 업로드합니다.
- 현재 프로젝트를 삭제한 뒤 같은 내용을 다시 저장할 때, 삭제된 음원 경로를 재사용하지 않습니다. 다른 프로젝트가 참조하는 음원도 삭제하지 않습니다.
- 저장 실패 후 다시 저장해도 같은 프로젝트 ID를 사용하며, 저장/불러오기/삭제 요청은 겹쳐 실행되지 않습니다.
- 프로젝트 불러오기는 이전 음원을 먼저 분리하고 완료된 음원만 연결합니다. 실패하면 실제 오류와 복구 안내를 표시하며 자막 기록은 유지합니다.
- 현재 작업의 음원 원본은 브라우저 메모리에 유지합니다. 새 프로젝트나 음원 변경 시 교체되며, 파일 업로드는 50MB 이하를 지원합니다.
- 회귀 검증: `npm test`, `npm run lint`, `npm run build`. 로컬 서버는 실행하지 않습니다.

- 싱크 수정 복구 기능 추가: 이전 취소 이력, 자막 번호와 시간 복원, 다시 찍기 위한 자동 일시정지, 음원/가사/메모를 보존하는 전체 싱크 리셋 및 리셋 취소
- 구간 저장/재불러오기 오류 수정: 삭제된 음원 경로 재사용 차단 및 원본 자동 재업로드, 저장 요청 중복 방지, 저장 중 추가한 싱크의 미저장 표시, 구간 종료 시간 스냅샷, 오류 메시지 보존
- 싱크 편집과 싱크 재생 모드 분리: 편집은 클릭으로만 진행하고, 불러온 프로젝트는 기록한 시간으로 재생하며 미기록 자막은 임의 시간으로 전환하지 않음
- 싱크 시간 경계, 연속 기록, 부분 저장, 삭제 후 저장, 음원 누락/네트워크 오류 회귀 테스트 추가
